# ARPC2 analysis result download

Download the prepared result archive using the link below. On the ZIP file page, choose **Download raw file** (the download-arrow icon).

- [ARPC2_results_and_code.zip](exports/ARPC2_results_and_code.zip)
- [SHA256 checksum](exports/ARPC2_results_and_code.zip.sha256)

The archive contains the generated A–E figures in PDF, SVG, TIFF and PNG formats, Chinese analysis report, English Results and figure legends, CSV/Excel statistical tables, analysis scripts, and download provenance.

Extract the ZIP on your computer and read `reports/analysis_report_zh.md` for methods and limitations. These are the existing generated results; this download branch does not add a new analysis or publication review.

Raw GEO matrices are retained in the cloud workspace and are excluded from this small download archive.
